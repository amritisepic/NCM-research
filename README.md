# NCM research: improving on Next-Concept Modeling at small compute

Working repository for a small-compute study of Next-Concept Modeling (NCM; Kumbong, Khare et al.,
arXiv 2610.14162, code github.com/HazyResearch/ncm). Start with `STATE.md` (current phase, live
hypotheses, compute, next actions); every run is logged in `log.md`; machine-readable results are in
`results/`; every config that produced a reported number is in `configs/`.

## Layout
- `src/ncmr/ncm_ref/` — unmodified upstream NCM code (MIT), vendored at the commit in `UPSTREAM_COMMIT`.
- `src/ncmr/` — our code: loaders (`ncm_ref_loader.py`), data and fixed splits (`data.py`), Sudoku tools
  (`sudoku.py`), token classes (`token_classes.py`), evaluation suite (`eval_text.py`), models
  (`models.py`: NCM tokenizer/generator via upstream modules, AR baseline, within-level-AR probe),
  training loop (`train.py`), FLOP formulas (`flops.py`).
- `scripts/` — entry points (reproduction, analyses, training, sampling, evaluation).
- `notebooks/` — Colab notebooks (generated by `notebooks/make_notebooks.py`); each resumes from Drive.
- `docs/` — literature/candidates, compute model, findings.

## Data and checkpoints (not in git)
```
# released checkpoints and data (HF): see scripts in STATE.md / log.md, or:
curl -L -o data/tinystories/train_bpe_8192.bin https://huggingface.co/datasets/hazyresearch/ncm-datasets/resolve/main/tinystories/train_bpe_8192.bin
```
Fixed splits (`src/ncmr/data.py`): train = NCM train stream; val = even-index validation stories;
test = odd-index validation stories (final numbers only).

## Reproduce Phase-0 numbers (CPU is enough)
```
python scripts/repro_sudoku.py --level hard          # released Sudoku checkpoint, 2000 test boards
python scripts/analyze_tokenizer.py --n 2000          # per-level / per-token-class reconstruction
python scripts/probe_invariance.py --n 1000           # bag-of-words probe of coarse codes
```
