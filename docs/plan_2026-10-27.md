## 4. Tracks
### C1 — E1: how much of NCM's code NLL is representation choice? (primary (c) candidate; eval-only)
- **Quantities** (window x, canonical codes c*, reconstruction x^ = D(c*), cut level k): `N_k = -log Q(c*_{>=k} | c*_{<k})`
  (teacher-forced, fp32); `rho_k = P(D(c*_{<k}, C_{>=k}) = x^)` with `C_{>=k}` sampled ancestrally from the model at
  T = 1 (Monte Carlo, up to 2048 samples per window, stopping at 20 hits); text term `T_k = -log rho_k`; representation
  term `R_k = N_k - T_k >= 0`, a lower bound on the nats spent choosing the encoder's code among codes that decode to
  the same text (exact token equality). Upper bound on text NLL: `U_k = -log Q(c*_{<k}) + T_k`. Cuts k = 5..11,
  reported only where hits are observed.
- **Models:** TinyStories A0, A1, A2, A4 (W1 seed 0, on Drive); WMT14 J0, J1, J2-F (target given source); Sudoku-hard
  released (board equality).
- **Predictions (to register):** released TinyStories `R_8 >= 0.8 N_8`; for A2 - A1, A4 - A1 and J1 - J0,
  `|dT_8| <= 0.2 |dN_8|` (the NLL gains are representation choice); the ordering by `T` or `U` matches the quality
  ordering where the ordering by `N` does not. Overturned if `R_8 < 0.5 N_8`, or if `dT_8` carries >= 50% of `dN_8` in
  two of the three comparisons.
- **Why it matters:** turns four anomalies (A2, A4, A1, J1) into one measured decomposition, says how much of the
  862 nats/window is not text likelihood, and supplies the selection metric any later method should use.
- **Replication unit:** domains and checkpoints (released models have no training seeds). Needs the user's agreement
  that this counts as "replicated" for (c).
- **Cost / prior:** ~1.5-2 CU (one notebook) + CPU analysis; P(prediction 1) ~0.7, P(dissociation explained) ~0.5.
- **E2 (exploratory, same notebook; design to be reviewed):** the cost of independent draws, without a joint model.
  For A0 / A1 / A3 at levels 3-6: damage from resampling one position, its neighbour, both independently, and a far
  pair (disjoint footprints), finer levels resampled with common random numbers. Astra's mode-mixing bridge predicts a
  positive adjacent-pair interaction, larger in A3 than A1, and ~0 for far pairs.

### D — criterion (d) close-out
- **D1 (~1.5 CU, eval-only):** batch-1 latency on A100-40GB (primary) and L4, fp32 with TF32 off (the precision of
  the quality numbers) and bf16 (secondary), 256 items, warm-up excluded, synchronised per item. WMT14: J0
  sequential (the fastest sequential decoder we have), J0 Jacobi exact, J0 and J2-F Jacobi + stability stop. Sudoku:
  sequential vs Jacobi + verifier stop. Attention-inclusive FLOPs computed for every configuration.
- **Gate:** the text half stays alive only if J2-F + stability stop takes <= 0.75x J0 sequential's mean latency in
  fp32 **and** the rule's val BLEU is within 1 of J0's (needs the references). The Sudoku half is alive if verifier
  stop <= 0.75x sequential.
- **Prior:** Sudoku passes (fewer passes and ~0.69x the positions). Text needs a Jacobi pass (~3.3x the positions of
  an average sequential step) to cost <= 1.06x a step's time: plausible only deep in the latency-bound regime. ~20%.
- **If the text gate passes:** register J1d (the stop rule fixed on val), run J2-F and J1 seeds 1-2 (~23 CU), score
  test once per seed; J0 and J1 with the same rule are the comparators. Then stop and ask (brief, criterion d).
- **If it fails:** (d) is reported as unreachable on text for this model family under the wall-clock rule, with the
  cost model and the Sudoku timing. A careful null.

### S0 — gate for Astra's direction 1 (CPU)
- Released TinyStories generator, frozen. Held-out log-likelihood gain from adding the canonical left-neighbour code
  to the factorized head (low-rank, zero-initialised bilinear term on frozen hidden states), per level 1-6; 4096

- Gate for a <= 5 CU coupled-sampler pilot: summed gain at levels 1-5 >= 10 nats/window and >= 5% of those levels'
  canonical NLL, **and** E2's adjacent interaction positive. Otherwise direction 1 is dropped and reported.
- CPU ~1-2 h on the laptop (needs the released checkpoints locally) or ~0.3 CU.
